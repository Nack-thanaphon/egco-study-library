## คาบ 1 — Data Mining, KDD และจริยธรรมข้อมูล

### เรียนอะไร

- `Data → Information → Knowledge → Wisdom`
- KDD: เตรียมข้อมูล → หาแบบแผน → ตรวจผล → นำความรู้ไปใช้
- Classification, Regression, Clustering และ Anomaly Detection
- Supervised กับ Unsupervised Learning
- Ethics, Privacy, Bias และ MLOps

### อธิบายแบบง่าย

ให้นึกถึงข่าวรถติด:

- รหัสเซ็นเซอร์หนึ่งชุดเป็น **Data**
- รู้ว่ารหัสนั้นคือไฟแดงหน้ามหาวิทยาลัยเป็น **Information**
- รู้ว่าช่วงนี้รถติดเป็น **Knowledge**
- เลือกออกจากบ้านเร็วขึ้นเป็น **Wisdom**

งานวิเคราะห์ก็เหมือนเลือกเครื่องมือให้ตรงงาน:

- **Classification:** ติดป้าย เช่น “โกง/ไม่โกง”
- **Regression:** ทำนายตัวเลข เช่นยอดขาย
- **Clustering:** จัดของที่คล้ายกันไว้กลุ่มเดียว โดยยังไม่มีป้าย
- **Anomaly Detection:** หาเหตุการณ์แปลก เช่นบัตรเครดิตใช้ผิดพฤติกรรม

### อาจารย์เน้น

โมเดลแม่นไม่พอ หากมีอคติ ละเมิดความเป็นส่วนตัว หรือไม่มีคนดูแลหลังนำไปใช้

## คาบ 2 — Exploring Data และ Data Quality

### เรียนอะไร

- **Instance** = หนึ่งแถวหรือหนึ่งตัวอย่าง
- **Attribute/Feature** = หนึ่งคุณสมบัติหรือหนึ่งคอลัมน์
- Nominal, Ordinal, Interval และ Ratio
- Record, Matrix, Document, Transaction, Graph และ Ordered Data
- Missing value, Noise, Outlier, ข้อมูลซ้ำ และข้อมูลไม่สอดคล้อง
- Mean, Median, Variance, Standard Deviation, Range และ IQR

### วิธีจำชนิดข้อมูล

**ชื่อ → เรียงได้ → ลบกันได้ → หารเป็นสัดส่วนได้**

1. **Nominal:** เป็นชื่อหรือประเภท เช่นกรุ๊ปเลือด
2. **Ordinal:** เรียงได้ เช่นน้อย–กลาง–มาก
3. **Interval:** ผลต่างมีความหมาย แต่ไม่มีศูนย์แท้ เช่นองศาเซลเซียส
4. **Ratio:** มีศูนย์แท้ จึงพูดว่า “สองเท่า” ได้ เช่นน้ำหนัก

### เปรียบเทียบ Mean กับ Median

Mean เหมือนหารค่าอาหารเท่ากันทุกคน หากมีคนสั่งของแพงมาก ค่าเฉลี่ยจะถูกดึงขึ้น ส่วน Median เหมือนเรียงบิลแล้วหยิบบิลตรงกลาง จึงทนต่อค่าที่โดดกว่ามากกว่า

### งานที่ปรากฏในหลักฐาน

- คำนวณ sample mean, variance, standard deviation, median, quartiles, range และ IQR จาก yield strength 11 ค่า
- ตรวจ ID ซ้ำ วันที่ต่างรูปแบบ ค่าหาย หมวดหมู่ผิด และข้อมูลขัดแย้งในตารางบุคคล

## คาบ 3 — Visualization และ Data Preprocessing

### เรียนอะไร

- Histogram, Boxplot, Scatter Plot และ Correlation Matrix
- Data Cleaning และวิธีจัดการ Missing Value
- Outlier ด้วย Z-score และ IQR
- Min-Max Normalization และ Z-score Standardization
- Sampling, Aggregation และ Discretization
- Feature Selection, PCA และ LDA

### ภาพจำสำคัญ

- **Preprocessing** เหมือนล้างและหั่นผักก่อนปรุง: Garbage In → Garbage Out
- **Normalization** เหมือนเปลี่ยนไม้บรรทัดหลายหน่วยให้ใช้สเกลเดียวกัน
- **Feature Selection** เหมือนเอาของที่ไม่ใช้หรือซ้ำกันออกจากกระเป๋า
- **PCA** เหมือนเลือกมุมถ่ายรูปที่เห็นความแตกต่างมากที่สุด
- **LDA** เหมือนเลือกมุมถ่ายรูปที่ทำให้กลุ่มที่มีป้ายแล้วแยกจากกันชัดที่สุด

### สูตรที่ต้องเข้าใจ

- Min-Max: `ค่าใหม่ = (ค่าเดิม − ค่าต่ำสุด) / (ค่าสูงสุด − ค่าต่ำสุด)`
- Z-score: `Z = (ค่าเดิม − ค่าเฉลี่ย) / ส่วนเบี่ยงเบนมาตรฐาน`
- IQR: `IQR = Q3 − Q1`
- Pearson correlation มีค่าระหว่าง `−1` ถึง `+1`; เครื่องหมายบอกทิศ ขนาดบอกความแรง

อย่าจำสูตรอย่างเดียว ให้ถามทุกครั้งว่า “สูตรนี้กำลังเปรียบเทียบค่าเดิมกับอะไร”

### งานที่ปรากฏในหลักฐาน

- In-class 0.5 คะแนน: Normalize และ Standardize ส่วนสูง 14 คนใน Excel
- หา Pearson r ของ `(160,55), (170,65), (180,75)`
- เลือกฟีเจอร์ที่ useful/irrelevant สำหรับทำนายราคาบ้าน
- วิเคราะห์ความสัมพันธ์ระหว่างขนมกับน้ำอัดลม และสร้างฟีเจอร์รวมหนึ่งตัว

กำหนดส่งในข้อความผูกกับ “เที่ยงคืนวันที่เรียน” แต่หลักฐานระบุวันที่เรียนไม่ตรงกัน ต้องตรวจ Classroom ก่อนใช้เป็นกำหนดส่งจริง

## คาบ 4 — Data Warehouse, OLAP และ Power BI

### เรียนอะไร

- Data Warehouse และคุณสมบัติ 4 ข้อ
- Data Cube กับมิติสินค้า ร้าน และเวลา
- Roll-up, Drill-down, Slice, Dice และ Pivot
- ROLAP, MOLAP และ HOLAP
- Star, Snowflake และ Fact Constellation
- Power BI: Import → Model → Visualize → Slicer → Measure

### อธิบายแบบง่าย

- **Data Warehouse** เหมือนตู้เย็นกลางบ้านที่รวมของจากหลายร้านและจัดให้เป็นระเบียบ
- **Data Mart** เหมือนช่องเฉพาะของแต่ละคนหรือแต่ละแผนก
- **Data Cube** เหมือนลูกบาศก์รูบิคที่หมุนดูยอดขายตามสินค้า ร้าน หรือเวลา
- **Roll-up** เหมือนดูยอดรายวันแล้วรวมเป็นรายเดือน
- **Drill-down** เหมือนกดจากยอดรายเดือนลงไปดูแต่ละวัน
- **Slice** เลือกค่าหนึ่งมิติ เช่นเฉพาะวันที่ 1
- **Dice** เลือกช่วงย่อยหลายมิติพร้อมกัน

### งานที่ปรากฏในหลักฐาน

ทำ Power BI dashboard **หนึ่งหน้า** ที่มี KPI, Sales Trend, Product Performance, Customer Analysis, Sales by Category และ Slicer พร้อมตอบคำถามเรื่องสินค้าขายดี ลูกค้ารายได้สูงสุด แนวโน้มยอดขาย ความต่างแต่ละหมวด และ Average Order Value

## Association Analysis — คาบที่ 5 (สอนแล้ว 20 ก.ย. 2569)

เดิมถือว่าเป็นเพียงบทเตรียมเรียน แต่ตอนนี้มี transcript ไฟล์เสียงของคาบ 20 กันยายน 2569 ยืนยันแล้วว่าสอนจริง จึงอัปเดตเป็นคาบ 5

### เรียนอะไร

- Association Analysis / Market Basket Analysis: หาไอเทมที่ถูกหยิบพร้อมกันบ่อย
- Itemset, Transaction, K-itemset, Frequent itemset (support ≥ min-support)
- กฎ X → Y หมายถึงเกิดพร้อมกัน ไม่ใช่เหตุผล
- สูตร support, confidence และ lift
- Apriori ใช้ anti-monotone ตัด candidate, FP-Growth ใช้ FP-tree ไม่ต้อง generate candidate
- Maximal frequent itemset, Closed itemset และความสัมพันธ์ Maximal ⊆ Closed

### อธิบายแบบง่าย

- **Support** = ความถี่ที่ชุดนั้นโผล่ใน transaction ทั้งหมด (นับครั้งหาร N)
- **Confidence** = ในบรรดาที่มี X อยู่ มีกี่ส่วนที่มี Y ตามมา (คล้าย conditional probability)
- **Lift** = เทียบว่ามี X ช่วยให้ Y น่าจะเกิดขึ้นกว่า random หรือเปล่า
- **Anti-monotone** = ถ้าคู่เล็กไม่บ่อยพอ คู่ใหญ่ที่มีคู่เล็กอยู่ก็ไม่ต้องดูต่อ
- **Maximal** = frequent ตัวใหญ่สุดที่ไม่มี superset ที่ยัง frequent, **Closed** = ไม่มี superset ที่ support เท่ากัน
- **ข้อควรระวังของ confidence** = กฎชา→กาแฟ 0.75 ดูดี แต่คนดื่มกาแฟอยู่แล้ว 90% กฎจึงไม่เพิ่มข้อมูลใหม่

### งานที่ปรากฏในหลักฐาน

- Exercise ในห้อง: กฎ 7 ข้อจาก {ขนมปัง, นม, ผ้าอ้อม} เช็ค min-support 0.4 / min-confidence 0.5
- Exercise 2: หา maximal/closed itemset (min-support 2)
- Exercise 3: สร้าง association rules (min-support 0.6 / min-confidence 0.5) ได้ 8 กฎ
- โจทย์เสริมในสไลด์: min-support 0.3 / min-confidence 0.6 (เซ็ตใหม่)
- งานส่งในคาบ: กระดาษคำนวณ เขียนชื่อ-รหัส ส่งท้ายคาบ

### คำถามที่เจอในห้อง

- เบียร์ต้องแยกยี่ห้อไหม → ขึ้นกับความละเอียดที่ต้องการ ถ้าสนใจแบรนด์ค่อยแยก ไม่สนก็รวมกลุ่ม (บาร์โค้ดใช้ได้)
- ครั้งหน้าเรียน Cluster Analysis; 4 ต.ค. ใช้ RapidMiner; สอบ midterm หลังวันที่ 11 ต.ค.
